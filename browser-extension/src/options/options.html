Optional automatic warning mode

Coverage and limits

  • Only URL analysis is supported. QR images, transaction simulations, and community reporting remain in the web app.
  • URL credentials, query values, and fragments are removed by the extension before a scan request.
  • The backend performs static local structure analysis only. It does not visit websites, follow redirects, or prove a site safe.
  • Disconnecting clears the session-only extension token. Normal account logout or session revocation also invalidates it server-side.
